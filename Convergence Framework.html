# Master GUI Launcher -- tum araclari tek panelden yonet
$ cd /home/enes/Desktop/araclar
$ python3 gui_launcher.py
 
# Her aracin GUI ve CLI butonlari mevcut
# Arac secip GUI'yi baslatmak icin tiklayin
# Convergence Hub -- API + Dashboard
$ cd 15_convergence/backend
$ pip install -r requirements.txt
$ python convergence.py
 
# API: https://localhost:8443
# Master GUI:
$ cd 15_convergence && python gui.py
# Tek arac -- CLI
$ cd 01_neuralrecon
$ pip install -r requirements.txt
$ python neuralrecon.py scan --scope 10.0.0.0/24
 
# Tek arac -- GUI
$ python gui.py
# GhostMesh (Go)
$ cd 02_ghostmesh
$ go mod tidy
$ go build -o ghostmesh ./cmd/
$ ./ghostmesh keygen
$ ./ghostmesh node --listen :9001 --key key.bin
 
# MindForge Agent (Go)
$ cd 06_mindforge/cmd/agent
$ go build -o mindforge-agent .
$ ./mindforge-agent --target-dir /path --flush-interval 30
Is Akisi

Tipik Red Team Operasyonu

Kesif

NeuralRecon ile hedef ag taramasi. LLM karar motoru sonraki adimlari belirler.

python neuralrecon.py scan --scope 10.0.0.0/24

Planlama

ArchitectMaster kesif sonuclarina gore saldiri plani uretir.

python architectmaster.py plan --tech-stack windows-ad

Altyapi

GhostMesh ile sifreli C2 mesh agi kurulur. QuantumVeil ile gizli kanallar olusturulur.

./ghostmesh node --listen :9001 --key key.bin

Erisim

NeuralSocial phishing e-postalari uretir. MirrorForge vishing kampanyasi baslatir.

python neuralsocial.py generate --scenario password-reset

Sizma

CodeSmith exploit uretir. AdaptivePayload EDR kacinma stratejileri uygular.

python adaptivepayload.py simulate --strategy process-hollowing

Degerlendirme

ShadowChase/ThreatActor tespit testi. CognitiveHunt avlanma hipotezleri. ForensicShield iz analizi.

python shadowchase.py test-all --intensity 50
